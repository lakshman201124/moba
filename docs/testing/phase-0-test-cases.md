# Phase 0 test cases: baseline of today's behaviour

**Phase:** 0 (Foundation and quick wins), see `testing.md` section 5.
**Goal:** record how the diner side, the public API and the permissions behave *today*, before any Phase 1 change, so a regression turns a test red.
**Gate (exit criteria):** every baseline test passes locally, live smoke passes, change 0.5 (sign-up off) confirmed.

How these cases run:
- **local**: the real `site/` served by `tests/support/bridge.py` (same security headers as Vercel) calling the real SQL functions as `anon`, on a fresh clone of the template database for every test (`db` fixture). Tables `T1`–`T50` (QR = `qrFor(n)`, `T49` inactive), dishes and add-ons from `tests/support/data.js`, staff owner `STAFF_ID`, signed-in non-staff `NON_STAFF_ID`, `visit_order_minutes = 5`, `ordering_open = true`.
- **local+mock**: as local, plus `page.route()` to cut or lose one request.
- **live (read-only)**: `https://moba-h5ag.vercel.app` and the Supabase project in `site/config.js`. Page loads and API calls whose input fails its first validation check only. Nothing is created.
- Time passing is simulated in the database (`update public.table_visits set order_until = now() - interval '1 second'`), never with sleeps.
- Test titles: `@phase0 @p0|@p1|@p2 <ID> <what it proves>`, plus `@devices` (also runs on Pixel 7 and iPhone SE 320 px), `@needs-owner`, `@after-ship`.
- A case that fails because the **app** is wrong keeps the correct assertion and is wrapped in `test.fail()` with `// KNOWN BUG <id>: ...`, so the suite stays green today and flips red when the bug is fixed. Two such cases are planned: **P0-SEC-09** (F12/E14) and **P0-SEC-10** (new bug **P0-BUG-01**, found while writing these cases).
- Exact strings below are copied from `site/menu.js` (`GATES`, `STATUS_LABELS`, `handlePlaceError`, `updateTableFooter`, `renderDone`) and error codes from `supabase/migrations/20261102000100_visit_tokens.sql` and `20261011000400_api_staff.sql`. Public errors come back as HTTP 400 `{ "code": "P0001", "message": "<CODE>", "details": ... }` from both PostgREST and the bridge.

**Totals:** 56 cases (FLOW 6, GATE 8, EDGE 11, API 10, SEC 10, SMOKE 7, LAYOUT 4) plus the 3 existing framework cases. Priority: **24 P0 (43%)**, 24 P1, 8 P2.
